##Proyecto Veterinaria San Marcos

Trabajo semestral del curso DSY1104 – Desarrollo FullStack II.
Sitio web para la clínica veterinaria San Marcos: permite a los dueños de mascotas registrarse, iniciar sesión y agendar citas, y da acceso al personal (veterinarios/recepción) y al administrador para gestionar usuarios, catálogo de servicios y reportes.
Evaluación actual

Evaluación Parcial 1 (30%): desarrollo del frontend con HTML, CSS y JavaScript puro (sin frameworks, sin backend real).

Integrantes
-Felipe Droguett
-Benjamin Venegas
-Felipe Perez

##Cómo abrir el proyecto
Clonar o descargar el repositorio.
Abrir Pagina_principal.html en el navegador (no requiere servidor).
Estructura
Pagina_principal.html – página de inicio, punto de entrada del sitio.
login.html / registro.html – acceso y creación de cuenta de dueño.
Agendar-cita.html – formulario para solicitar una cita.
duenoHome.html, duenoCatalogo.html, duenoInfo.html – vistas del dueño de mascota.
adminHome.html, gestion_usuarios.html, gestion_Catalogo.html, gestion_reportes.html – panel de administrador.
veterinaria-login.html, veterinaria-panel.html, veterinaria-citas.html, veterinaria-fichas.html, veterinaria-historial.html, veterinaria-reportes.html – panel del personal de la clínica.
